# 基于哈希表的信用等级查询系统（C++ 课程设计）

按《实验要求.docx》第七题实现：用**链地址法**处理冲突的哈希表，通过 18 位身份证号完成数据导入、等级查询、修改、删除、插入、打印和文件保存。

## 二、在 VS2022 中运行（推荐）

1. 双击 `credit_system.sln`（或“文件 → 打开 → 项目/解决方案”选择它）。
2. 工具栏选择 `Debug` + `x64`，按 **F5**（调试）或 **Ctrl+F5**（不调试）运行。
3. 程序会直接在“信用等级查询系统”菜单下等待输入：先输 `1` 导入数据，再输 `6` 看哈希表结构。

工程已经配置好的几件事：

- **工作目录 = 工程目录**，所以 `722data.txt` 不用改路径就能导入；
- **生成后自动把 `722data.txt` 复制到输出目录**，所以直接双击 `bin\...\credit_system.exe` 也能用；
- **源文件按 UTF-8 解析**（`/source-charset:utf-8`），中文注释、菜单不会乱码；
- 输出目录为 `bin\$(Configuration)\$(Platform)\`，中间文件在 `obj\` 下。

若要修改数据文件路径，改 `main.cpp` 顶部的宏后重新生成即可（支持绝对路径，注意双反斜杠）：

```cpp
#define DATA_FILE "722data.txt"   // 例如改成 "D:\\722data.txt"
```

> 如果 VS 提示找不到 `v143` 工具集，用 Visual Studio Installer 勾选“使用 C++ 的桌面开发”工作负载即可。
> 注意：`main.cpp` 保存为 **UTF-8（带 BOM）**；如果用自己的编辑器改成 GBK 保存，需把工程属性“C/C++ → 命令行”里的 `/source-charset:utf-8` 去掉。

## 三、其它编译方式

**MSVC 命令行**

```bat
cl /EHsc /O2 /source-charset:utf-8 main.cpp /Fe:credit_system.exe
```

**g++ / MinGW / Dev-C++**

```bat
g++ -O2 -o credit_system.exe main.cpp -finput-charset=UTF-8 -fexec-charset=GBK
```

若终端中文显示乱码，先执行 `chcp 65001`，或用 `-fexec-charset=UTF-8` 编译后在 UTF-8 代码页下运行。

## 四、功能与函数对应关系

| 菜单 | 功能 | 函数 | 说明 |
| --- | --- | --- | --- |
| 1 | 数据导入 | `data_read(char filename[])` | 逐行读文件，每行调用 `Insert_hashtable` 建表 |
| 2 | 等级查询 | `Search_hashtable()` + `Value_level()` | 查到后按信用值输出 A/B/C/D 等级 |
| 3 | 数据修改 | `modify_hashtable()` | 按身份证号定位，改信用值（0-100） |
| 4 | 数据删除 | `del_hashtable()` | 摘链 + `delete`，头结点与中间结点都处理 |
| 5 | 数据插入 | `Insert_hashtable()` | 先查重，重复则提示失败；头插法入链 |
| 6 | 打印输出 | `print_hashtable()` | 按 `地址->(身份证号,信用值)->...` 输出 |
| 7 | 文件保存 | `save_hashtable()` | 遍历整表写回文件 |
| 0 | 系统退出 | `main()` | 释放全部结点后退出 |

另外还有 `Value_hashtable()`（哈希函数）、`Init_hashtable()`（初始化）、`Menu()`（菜单）、`Destroy_hashtable()`（释放内存）。

## 五、数据结构与算法

完全沿用实验要求给出的定义：`SIZE 12`、`M 11`、`PidType`、`KeyType`、`Hnode/*Hlink`、全局 `Hlink head[SIZE]`。

- **哈希函数**：数字分析法 + 除留余数法，取身份证号第 4、10、12、14、17 位组成整数：

  ```
  H(pid) = ((id[3]-'0')*10^4 + (id[9]-'0')*10^3 + (id[11]-'0')*10^2
           + (id[13]-'0')*10^1 + (id[16]-'0')) % 11
  ```

  表中用整数乘法代替 `pow()`，避免浮点误差。
- **冲突处理**：链地址法，插入用头插法，链表不带头结点。
- **内存管理**：全部使用 C++ 的 `new` / `delete`——结点由 `new (std::nothrow) Hnode` 分配，删除记录时先摘链再 `delete`，退出前用 `Destroy_hashtable()` 逐个 `delete` 回收；代码中已经没有 `malloc` / `free` / `NULL`。
- **查找长度**：平均 O(1+n/M)，最坏 O(n)；空间 O(n)。
- **关键点**：`PidType` 只有 18 个字节，装不下结束符 `'\0'`。因此
  比较一律用 `strncmp(pid, id, 18)`，输出一律用 `printf("%.18s", pid)`，
  不能直接 `strcmp` / `%s`，否则会越界读到脏数据（示例代码里的 `strcmp` 在这点上有隐患，本实现已修正）。
- **健壮性**：身份证号长度/字符校验（前 17 位数字，末位数字或 X）、信用值 0-100 校验、非数字菜单输入、文件打开失败、重复插入、删除/修改不存在的记录，均有提示且不会崩溃。
